New AI tools arrive every week. Instead of chasing each one, I survey them with the same checklist, so the comparison stays fair and the decision stays quick.

## The checklist

- **Grounding.** Can it answer from my data, or only from its own memory?
- **Control.** Can I limit what it can read and stop it from changing anything?
- **Output.** Does it return a structure my code can validate?
- **Cost and speed.** What does one real task cost, and how long does it take?
- **Privacy.** Where does the data go, and who can see it?
- **Exit.** If I leave tomorrow, can I take my prompts, data and history with me?

## Try it on a real task

Demos are designed to impress. I always test with one small task from actual work — a messy spreadsheet, a real question from HR — and score the tool against the checklist.

## Write it down

A short note per tool — what it did well, where it failed, what it costs — turns scattered experiments into a survey I can reuse and share. This blog is where those notes will live.
